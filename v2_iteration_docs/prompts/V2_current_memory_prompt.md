请不要默认使用传统低通滤波器来处理力传感，而应优先按以下论文思想设计“力/触觉处理层”：

【总体原则】
1. 原始力/触觉信号可能噪声大、状态相关、难以校准，不要直接无脑送入策略。
2. 优先将原始力/触觉转换为低维、任务相关、可泛化的接触语义特征。
3. 当基础策略已存在时，优先把力/触觉作为“在线修正信号”，而不是完全替代主策略。
4. 在动作执行端加入平滑，减少高频抖动放大接触误差。

【优先实现的三层处理】
A. 接触语义提取层
- 输入：原始触觉阵列、关节力矩、接触/碰撞信息
- 输出：
  1) 每指是否接触
  2) 每指接触中心
  3) 每指法向力近似
  4) 每指切向力/滑移指标
  5) 接触持续时间
  6) 三指受力均衡度
- 目标：用低维接触表示代替高维稀疏原始传感

B. 力/触觉在线修正层
- 使用 base policy 的内部表征或当前动作意图作为 query
- 使用触觉/力觉嵌入作为 key/value
- 只在接触偏差、滑移风险、受力失衡时产生动作修正
- 不要始终对所有动作施加强修正

C. 动作平滑层
- 对输出动作加入指数滑动平均：
  u_smooth[t] = alpha * u[t] + (1 - alpha) * u_smooth[t-1]
- 初始可尝试 alpha = 0.5
- 目标：减少高频振荡、抖动刷分、接触不稳定

【如果必须尝试显式滤波】
按以下顺序尝试，而不是一开始就上复杂滤波器：
1. 滑动均值 / 指数滑动平均
2. 接触状态的滞回阈值
3. 滑移指标的时间窗口统计
4. 仅在必要时再试更复杂滤波器

【每轮迭代必须比较】
1. 直接用原始力输入
2. 用接触语义特征
3. 用接触语义 + 在线修正
4. 是否加动作平滑
5. 对 success rate、三指同时接触率、滑移率、抬升率、动作振荡幅度的影响

请按以下论文思想设计训练初始化，而不是只依赖全随机开局：

【初始化的三个层次】

请按以下论文思想设计状态空间，不要简单堆叠所有原始传感器：

【总原则】
1. 状态空间必须围绕任务可观测性和接触控制来组织
2. 优先使用低维、稳定、任务相关的状态，而不是高维原始信号
3. 对于 sim-to-real，actor 只用部署时可靠可得的观测；critic 可以使用更多特权信息
4. 如果任务具有明显时序依赖，状态空间必须包含历史信息，例如上一动作、接触持续时间或序列模型输入

【推荐状态空间分层】
A. 核心本体感觉层
- 关节角 q_t
- 关节角速度 dq_t
- 上一动作 a_{t-1} 或上一目标关节指令
- 末端执行器/指尖相对位姿

B. 物体相对状态层
- 方块相对掌心位置
- 方块相对掌心姿态
- 方块线速度 / 角速度（若可得）
- 目标抓取位 / 目标姿态误差（若任务定义中存在）

C. 接触语义层
- 每指是否接触
- 每指法向力近似
- 每指切向力或滑移指标
- 每指接触中心
- 接触持续时间
- 三指接触几何中心
- 三指受力均衡度
- 是否形成三指闭合接触的 surrogate 指标

D. 任务上下文层
- 当前任务命令
- 当前阶段标签（若采用课程学习/分阶段任务）
- 当前抓取模式或目标面标签（若已知）

E. 时序补充层
- 最近 K 步的关键接触状态
- 或使用 LSTM / GRU 代替显式堆叠

【actor-critic 非对称建议】
Actor:
- 只用真实部署可靠可得的信息
- 不使用难校准、强状态相关噪声的原始传感器

Critic:
- 允许额外使用仿真特权信息，如：
  1) 真实接触点
  2) 真实接触法向
  3) 真实摩擦系数
  4) 物体真实速度
  5) 随机化参数
  6) 更完整的力矩/接触状态

【对三指捏握抓方块任务的最低建议状态】
1. 方块相对掌心位姿
2. 三目标手指末端相对方块的位置
3. 每指接触标志
4. 每指法向力
5. 每指切向滑移指标
6. 上一动作
7. 接触持续时间
8. 三指受力均衡度

【不要优先采用的状态】
1. 未处理的高维原始触觉阵列
2. 强状态相关、难校准的原始力信号
3. 与任务无关的全局场景冗余信息

- DR 训练步数应至少 20M（DR 增加探索难度需要更多步数）
- 启用 DR 后必须对比有/无 DR 的关键指标变化

## 穿模修复记录（C20, 2026-04-20）

### 问题
用户视频检查发现手指capsule碰撞体与方块存在穿模（互相穿透）。

### 原因分析
1. `solref="0.01 1.2"`: dampratio=1.2 过阻尼，接触响应偏软
2. `solimp="0.95 0.995 0.0005"`: width=0.0005m (0.5mm) 穿透容差过大
3. `iterations=12, ls_iterations=16`: 求解器迭代次数偏少，接触约束求解精度不足
4. 方块无 solref/solimp 设置（使用 MuJoCo 默认值）

### 修复内容
| 参数 | 修改前 | 修改后 | 文件 |
|:---|:---|:---|:---|
| 手指 solref | 0.01 1.2 | 0.005 1.0 | right_hand_v2_vertical_coacd.xml |
| 手指 solimp | 0.95 0.995 0.0005 | 0.97 0.999 0.0001 | right_hand_v2_vertical_coacd.xml |
| 求解器 iterations | 12 | 20 | right_hand_v2_vertical_coacd.xml |
| 求解器 ls_iterations | 16 | 20 | right_hand_v2_vertical_coacd.xml |
| 方块 solref/solimp | 无(默认) | 0.005 1.0 / 0.97 0.999 0.0001 | small_cube.xml |

### 预期效果
- 接触响应时间从 10ms → 5ms（更快响应穿透）
- 穿透容差从 0.5mm → 0.1mm（5倍减少）
- 阻尼从过阻尼(1.2) → 临界阻尼(1.0)（更稳定）
- 求解器精度提升（20次迭代 vs 12次）

### 注意
穿模修复改变了接触物理，之前的 checkpoint 不能直接恢复使用，C20 必须从头训练。
